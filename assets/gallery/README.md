# Status-line gallery

Extra screenshots of the two status lines across scenarios (many agents, worktree, light
theme, drift, narrow terminal…). The two **primary** shots live one level up and are embedded
in the repo README — `../status-line.png` (main bar) and `../subagent-status-line.png` (panel);
replace those in place when the canonical look changes. Everything else goes here.

## Naming

`<renderer>-<scenario>.png`, lower-case, hyphenated:

- `<renderer>` — `main` (the bar) or `panel` (the running-agent view).
- `<scenario>` — what the shot demonstrates: `many-agents`, `worktree`, `light-theme`,
  `drift`, `narrow`, `compaction`. Add a date suffix (`-YYYY-MM`) only for historical
  snapshots kept for comparison.
